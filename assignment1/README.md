# Handwritten Digit Recognition — Assignment 1

Мини-проект по распознаванию рукописных цифр **0–9**. Отчёт и ноутбук — на английском, инструкция и демо — на русском.

## Что выполнено

Подготовлены 2 000 изображений MNIST (200 на класс), обучены logistic regression и CNN, сохранены модели, выполненный ноутбук, метрики, confusion matrices, графики и пятистраничный отчёт. Добавлены CLI-распознавание и локальное демо для рисования цифр.

**Ограничение:** задание требует самостоятельно собранный датасет. Здесь используется открытый MNIST; техническая часть выполнена, требование самостоятельного сбора — нет. Не описывайте эти изображения как собственный сбор. Математические знаки в обученную модель не входят.

## Реальные результаты

| Model | Accuracy | Macro precision | Macro recall | Macro F1 |
|---|---:|---:|---:|---:|
| Logistic regression | 89.00% | 89.11% | 89.00% | 88.89% |
| CNN | 98.33% | 98.47% | 98.33% | 98.35% |

Test: 300 изображений, по 30 на класс. Ошибки: 33 и 5. Разница accuracy: 9.33 процентного пункта. Эти результаты относятся к одному запуску и конкретному разбиению. Источник: `results/model_comparison.csv`.

## Запуск на этом компьютере

Откройте PowerShell в папке проекта:

```powershell
.\.venv\Scripts\python.exe demo.py
```

Откройте **http://127.0.0.1:8765**, нарисуйте цифру и нажмите «Распознать». Остановка: Ctrl+C в терминале. Рисунок обрабатывается локально и не сохраняется. Работа с вашим рисунком может отличаться от качества на MNIST.

Для PNG/JPG с одной тёмной цифрой на светлом фоне:

```powershell
.\.venv\Scripts\python.exe predict.py "путь\к\цифре.png"
```

Обрежьте изображение вокруг одной цифры с небольшим отступом. CLI использует предобработку ноутбука. Демо дополнительно обрезает поле рисования по штрихам. Страницы целиком и математические выражения не поддерживаются.

## Устройство эксперимента

На каждый класс: 140 train, 30 validation, 30 test. Test выбран из официального test MNIST; остальные — из официального train. Идентификаторы авторов отсутствуют, поэтому разделение validation по авторам не заявляется. Хэши и исходные индексы исключают точные дубликаты.

Предобработка: grayscale → inversion → вписывание в 24×24 → дополнение до 32×32 → деление на 255. Аугментация только train: небольшой поворот и смещение, одна копия каждого изображения. Обе модели видят одинаковые 2 800 входов. Logistic regression: C=0.1, выбранное на validation. CNN: Adam, lr=0.001, dropout=0.4, batch=64; выбран checkpoint эпохи 20 из 26 выполненных. Test не используется для выбора моделей.

## Как выполнить требование собственного датасета

Соберите по 200 оригинальных изображений каждого класса: например, 20 человек × 10 написаний каждой цифры. Формат: `data/raw/0/w01_001.png`, `data/raw/1/w01_001.png` и т. д. Префикс w01 означает одного и того же человека во всех классах. Аугментированные копии не являются новыми оригинальными изображениями.

В `self_collected_template.ipynb` w01–w14 используются для train, w15–w17 для validation, w18–w20 для test. Запускайте шаблон в отдельной копии проекта, чтобы не смешать результаты. Для символов добавьте папки `plus`, `minus`, `multiply`, `divide`, `equals` с аналогичным количеством оригиналов. После обучения подготовьте новый отчёт по новым метрикам: имеющийся PDF описывает только MNIST.
