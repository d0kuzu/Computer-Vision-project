# Объяснение проекта для защиты

## Идея

Сравниваются logistic regression и CNN для классификации одной рукописной цифры. Классов десять, от 0 до 9. Целые выражения и математические знаки в этот эксперимент не входят.

## Данные

Использованы 2 000 изображений открытого MNIST, по 200 каждого класса. Это не самостоятельный сбор; это ограничение соответствия заданию. Нельзя утверждать, что цифры написали участники нашей группы.

Train: 1 400 изображений, validation: 300, test: 300. Validation нужна для выбора параметров и остановки, test — для итоговой независимой проверки. Такая схема уменьшает риск подгонки под тест.

## Предобработка

Grayscale, инверсия, пропорциональное уменьшение и помещение в поле 32×32. Нормализация пикселей к 0–1. К каждому обучающему изображению добавляется слегка повёрнутая/сдвинутая копия. Validation и test не аугментируются. Перевороты исключены, поскольку могут менять смысл цифры.

## Модели

Logistic regression работает с вектором из 1 024 пикселей и линейными границами классов. CNN учитывает локальные связи пикселей, выделяя штрихи и формы. Обе модели получают одинаковые обучающие входы.

CNN содержит три свёрточных блока (32, 64, 128 каналов), ReLU и max pooling. Затем dense-слой, dropout 0.4 и десять выходных значений. Loss — cross-entropy; оптимизатор — Adam. Выбрана 20-я эпоха по validation macro F1. После шести эпох без улучшения обучение остановилось на эпохе 26.

## Метрики и результаты

Accuracy — доля правильных ответов. Precision — доля правильных предсказаний среди ответов выбранного класса. Recall — доля найденных объектов этого класса. F1 объединяет precision и recall. Macro даёт каждому классу одинаковый вес.

Logistic regression: accuracy 89.00%, macro F1 88.89%, 33 ошибки из 300.

CNN: accuracy 98.33%, macro F1 98.35%, 5 ошибок из 300. Разница accuracy: 9.33 процентного пункта.

В confusion matrix строки — истинная цифра, столбцы — предсказанная. Диагональ — правильные ответы. Ошибки показаны в `results/cnn_errors.png`.

## Ограничения

Небольшой test, один seed, неизвестные ID авторов, чистые MNIST-изображения вместо фотографий. Нельзя обещать 98.33% на любом почерке. Softmax в демо не является откалиброванной вероятностью правильного ответа.

Следующий шаг: собственные изображения, разделение по авторам, несколько запусков и добавление математических знаков как новых классов.
